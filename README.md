# Luke Evans - Personal Resume & Portfolio Website

A personal portfolio and interactive resume website built for IS 201. This project showcases coursework, professional experience, skills, and personal career goals using a responsive Bootstrap layout alongside custom-built HTML pages.

## Project Overview

This repository fulfills the IS 201 web development assignment requirements:
- **Bootstrap Customization:** Selected and customized an open-source Bootstrap template to display a professional resume, skills breakdown, and academic background.
- **Custom HTML Page (5-Year Plan):** Designed and coded an original HTML page from scratch (linked directly from the primary navigation) outlining personal, academic, and professional milestones over the next five years.
- **Embedded Media & Analytics:** Integrated a live Tableau data visualization dashboard and an embedded YouTube video directly into the layout.
- **Structured Content:** Implemented both ordered and unordered lists to clearly outline career milestones, skills, and academic coursework.
- **Visual Assets:** Curated and styled multiple images across both the template and custom pages for an engaging visual presentation.
- **Responsive Layout:** Structured to render smoothly across desktop, tablet, and mobile displays.

## Features

- **Interactive Resume:** Detailed timeline of work experience, education, leadership, and technical competencies.
- **Original 5-Year Plan Page:** Hand-coded HTML structure detailing strategic career checkpoints, target industry roles, and continuing education plans.
- **Tableau Data Visualization:** Interactive dashboard embedded into the web layout to demonstrate data analytics capabilities.
- **Multimedia Integration:** Embedded YouTube video player providing dynamic, context-relevant media.
- **Structured Lists:** Formatted bulleted lists for competencies and numbered sequential lists for multi-year milestones.
- **Image Gallery & Visuals:** Integrated multi-image styling throughout the user interface.
- **Custom Styling & Scripts:** Tailored CSS overrides and JavaScript components located in `/css` and `/js` for enhanced navigation and custom branding.
